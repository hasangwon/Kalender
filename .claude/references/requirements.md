# 요구사항 정리 (2026-08-21)

> 사용자 요구 원문을 작업 단위로 정리. 완료 시 체크.

## 1. 테마/디자인
- [ ] 애플 기본 앱과 구분되는 고유 테마. 테마색 3개 (Primary/Background/Accent), 색 과다 금지
- [ ] 현재 레이아웃 양식은 유지 (색·타이포 중심 개성화)

## 2. 일정 추가 UX
- [ ] "일정 없음" 영역 탭 → 일정 추가
- [ ] 상단 + 버튼 제거, 일정 있는 날은 목록 하단 "+ 일정 추가" 행

## 3. 앱 이름
- [ ] 표시 이름 "칼린더" (영문 Kalender) — 앱/위젯/문서

## 4. 햄버거 메뉴 (좌측 상단)
- [ ] 로그인 (예정 기능 — 비활성 표기)
- [ ] 부모님 생일 등록 (이름 + 음력 월/일 리스트 추가/삭제)
- [ ] 설정

## 5. 한국 공휴일
- [ ] 달력에 공휴일 반영 (날짜 빨강 + 선택일 목록에 공휴일명)
- [ ] 데이터: 연도별 하드코딩 테이블(2025~2027) — 수동 관리, 연도 추가 필요 주석

## 6. 음력
- [ ] 선택한 날짜 세부 헤더에 음력 날짜 작게 표시
- [ ] 등록된 음력 생일이 매년 양력 달력에 표시 (예: "엄마 생일")
- [ ] 변환: Calendar(identifier: .chinese), 윤달 제외

## 7. 위젯 (핵심)
- [ ] Large 달력형 위젯: 월 그리드 크게, 날짜 아래 일정 제목, 길면 "…" 말줄임
- [ ] 위젯 탭 → 앱 열림
- [ ] 기존 Small/Medium 유지, 공휴일/생일/유형색 반영

## 8. 반복 유형별 색
- [ ] 일정 색 = 반복 유형(단일/매주/매달)이 결정 — 일정별 색 선택 제거
- [ ] 8색 팔레트, 설정에서 유형별 색 변경 (중복 지정 허용)
- [ ] 색 설정은 App Group UserDefaults (위젯 공유)
- [ ] 생일 표시 색: 분홍 고정

## 결정 사항
- 프로젝트/타깃명(PlanWidget)은 유지, 표시 이름만 "칼린더"
- 공휴일 대체공휴일 포함 하드코딩 (설/추석 연휴는 일요일 겹침만 대체, 기타 지정 공휴일은 토/일 대체)
- 로그인은 추후 카카오 (메뉴에 비활성 항목만)

- [ ] 완료 버튼 → X 아이콘, "생일 추가"를 프라이머리 버튼답게

# 플랫폼 구현 현황

## 2026-10-19 안드로이드 1차 구현 메모

- 에뮬레이터(Pixel 8, API 36)에서 확인: 달력·월 넘기기·일정 폼·설정·기념일·동기화·검색·정보·위젯 3크기·하루 알림 표시.
- 실기기·실제 런처에서 미확인: 위젯 크기 조절 시 구간 전환, 정확 알람의 실제 시각 정확도, 안드로이드 달력 실제 일정 표시, 태블릿 레이아웃.
- `.redcalendar` 가져오기는 iOS 해석기를 그대로 옮겼으나 실제 파일로 검증하지 않았다 — 파일을 받으면 `common/fixtures/` 에 넣고 테스트 추가.

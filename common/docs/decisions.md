## 2026-10-19 — 안드로이드 1차 구현 중 결정

| 결정                    | 내용                                                                                       | 이유                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------- |
| 위젯은 Glance 로 확정    | Large 달력 그리드(7×6, 칩 2줄, +N)가 Glance 로 렌더링됨을 에뮬레이터에서 확인. 비트맵 대체 안 함 | 스파이크 통과                                                                               |
| 위젯 크기 모드          | `SizeMode.Exact` + 코드에서 Small/Medium/Large 구간 판정                                     | 달력 칸 글자 맞춤에 실제 폭이 필요. Responsive 구간 폭(250dp)으로 재면 넓은 위젯에서 글자가 덜 찬다 |
| 위젯 칩 글자 자르기     | 그리기 전에 Paint 로 폭을 재서 넘치는 글자를 미리 제거                                        | RemoteViews 는 말줄임(…)을 끌 수 없다. iOS 는 … 없이 글자 단위로 끊는다                      |
| compileSdk 37.2 / targetSdk 36 | Compose 1.12·core-ktx 1.19 가 compileSdk 37 요구. SDK 패키지명은 `platforms;android-37.2`  | Play 대상 API 요건은 36 으로 충족                                                            |
| 앱 아이콘               | 어댑티브 아이콘 배경 검정(#000000, iOS 아이콘 배경과 동일) + 전경 `cal-icon.png` 19% 인셋     | iOS 와 같은 아트워크 사용                                                                    |
| 업로드 키               | `android/keystore/upload-keystore.jks` + `android/keystore.properties` (git 무시)             | Play 앱 서명 사용, 분실 대비 별도 백업 필요                                                   |
| 시스템 글자 크기        | 무시하고 앱 설정 4단계만 적용 (`fontScale = 1` 고정)                                          | iOS 가 Dynamic Type 을 앱 설정으로 덮는 것과 동일한 동작                                      |
